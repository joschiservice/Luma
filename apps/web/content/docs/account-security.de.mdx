---
title: Anmeldung absichern
description: Ergänzen Sie Ihr Passwort um einen Code aus einer Authenticator-App, bewahren Sie Backup-Codes auf, melden Sie sich mit einem Passkey an und wissen Sie, was bei verlorenem Zugang zu tun ist.
---

Ihre Anmeldung schützt jeden Workspace, zu dem Sie gehören, einschließlich Genehmigungen und Änderungen in verbundenen Systemen. Unter **Einstellungen → Sicherheit** ergänzen Sie nach dem Passwort einen Code-Schritt oder fügen einen Passkey hinzu, der das Passwort ersetzt. Diese Einstellungen gehören zu Ihrem Konto und gelten in jedem Workspace.

## Zwei-Faktor-Authentifizierung einschalten [#turn-on-two-factor-authentication]

Mit Zwei-Faktor-Authentifizierung fragt Luma nach dem Passwort nach einem 6-stelligen Code aus einer Authenticator-App. Jede App mit zeitbasierten Codes funktioniert, etwa 1Password, Google Authenticator oder Microsoft Authenticator.

1. Wählen Sie unter **Authenticator-App** die Option **Einrichten** und geben Sie Ihr Passwort ein.
2. **Backup-Codes sichern** zeigt 10 Codes. Bewahren Sie sie sicher auf, etwa in Ihrem Passwortmanager; **Codes kopieren** kopiert alle. Sie sehen sie nicht noch einmal. Wählen Sie dann **Codes sind gesichert**.
3. Scannen Sie den QR-Code mit Ihrer Authenticator-App oder geben Sie den **Einrichtungsschlüssel** ein.
4. Geben Sie den 6-stelligen Code aus der App ein und wählen Sie **Einschalten**.

Die Zwei-Faktor-Authentifizierung beginnt erst, wenn der Code bestätigt ist. Schließen Sie den Dialog vorher, ändert sich nichts, und für die Anmeldung reicht weiterhin Ihr Passwort.

Wird ein Code abgelehnt, prüfen Sie, ob Ihr Gerät die Uhrzeit automatisch einstellt. Die Codes wechseln alle 30 Sekunden.

## Mit Code anmelden [#sign-in-with-a-code]

Nach E-Mail-Adresse und Passwort fragt Luma **Bestätigen Sie Ihre Identität**. Geben Sie den aktuellen Code aus Ihrer Authenticator-App ein und wählen Sie **Bestätigen**. Haben Sie Ihr Gerät nicht zur Hand, wählen Sie **Backup-Code verwenden**. Jeder Backup-Code funktioniert nur einmal.

Geben Sie den Code innerhalb von 10 Minuten nach dem Passwort ein. Ist der Anmeldeversuch abgelaufen oder haben Sie fünf falsche Codes eingegeben, wählen Sie **Erneut anmelden** und geben Ihr Passwort noch einmal ein. Nach wiederholt falschen Codes sperrt Luma die Code-Eingabe für 15 Minuten.

## Backup-Codes ersetzen [#replace-your-backup-codes]

Wählen Sie **Neue Backup-Codes**, geben Sie Ihr Passwort ein und wählen Sie **Codes erstellen**. Ihre bisherigen Codes funktionieren sofort nicht mehr. Tun Sie das, wenn Sie die meisten Codes verbraucht haben oder jemand anderes sie gesehen haben könnte.

## Passkey verwenden [#use-a-passkey]

Mit einem Passkey melden Sie sich per Fingerabdruck, Gesicht, Geräte-PIN oder Sicherheitsschlüssel an. Er kann nicht abgefischt und nicht auf einer anderen Website verwendet werden. Mit einem Passkey entfallen Passwort und Code.

1. Geben Sie unter **Passkeys** optional einen Namen ein, etwa „Arbeitslaptop“.
2. Wählen Sie **Passkey hinzufügen** und folgen Sie der Aufforderung Ihres Geräts.

Auf der Anmeldeseite wählen Sie **Mit Passkey anmelden**. Fügen Sie auf jedem Gerät, mit dem Sie sich anmelden, einen Passkey hinzu, es sei denn, Ihr Passwortmanager synchronisiert Passkeys zwischen Geräten. Die Liste zeigt bei jedem, ob es ein **Synchronisierter Passkey** oder ein **Passkey auf einem Gerät** ist.

Um einen Passkey hinzuzufügen, müssen Sie sich innerhalb des letzten Tages angemeldet haben. Bittet Luma Sie, sich vorher ab- und wieder anzumelden, tun Sie das und fügen dann den Passkey hinzu. Kann Ihr Browser keine Passkeys erstellen, verwenden Sie eine aktuelle Version von Chrome, Edge, Firefox oder Safari.

## Passkey entfernen oder Zwei-Faktor-Authentifizierung ausschalten [#remove-a-passkey-or-turn-off-two-factor-authentication]

Wählen Sie **Entfernen** neben einem Passkey und dann **Passkey entfernen**. Löschen Sie ihn auch auf Ihrem Gerät oder in Ihrem Passwortmanager.

Um keine Codes mehr zu verwenden, wählen Sie unter **Authenticator-App** **Ausschalten** und geben Ihr Passwort ein. Ihre Backup-Codes funktionieren dann nicht mehr. Hinzugefügte Passkeys funktionieren weiter.

## Wenn Sie den Zugang verlieren [#if-you-lose-access]

- **Authenticator-Gerät verloren**: Melden Sie sich mit einem Backup-Code oder Passkey an. Schalten Sie dann die Zwei-Faktor-Authentifizierung aus und richten Sie sie auf dem neuen Gerät neu ein.
- **Backup-Codes aufgebraucht**: Melden Sie sich mit Ihrer Authenticator-App oder einem Passkey an und wählen Sie **Neue Backup-Codes**.
- **Passwort vergessen**: Melden Sie sich mit einem Passkey an, falls Sie einen hinzugefügt haben. Auf der Anmeldeseite bietet Luma kein Zurücksetzen des Passworts an.

Ohne Authenticator-App, Backup-Code oder Passkey können Sie die Anmeldung nicht abschließen. Halten Sie mindestens zwei davon bereit.
