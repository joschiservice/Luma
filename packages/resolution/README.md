# @luma/resolution

Coordinates exception resolution: proposals, review, refresh, playbooks, follow-ups, learning, Shadow Mode measurement, activity and the operations overview.

Application orchestration depends on domain contracts; Temporal-specific behavior belongs to workflow-temporal. Proposal refresh rereads current evidence. Synthetic identifiers and scenario faults stay in simulator tooling. Cross-owner workspace reads belong to read-models.

## Public entry points

- `@luma/resolution`
- `@luma/resolution/composition`
- `@luma/resolution/http`
