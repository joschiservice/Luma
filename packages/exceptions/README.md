# @luma/exceptions

Detects and persists operational exceptions with their evidence, diagnoses, verification and escalation state.

Detection and diagnosis rules live here. Provider access is injected through application contracts. Proposal review and playbook execution belong to resolution and execution. Needs-you attention rules are exported as SQL building blocks for read-models.

## Public entry points

- `@luma/exceptions`
- `@luma/exceptions/composition`
- `@luma/exceptions/http`
