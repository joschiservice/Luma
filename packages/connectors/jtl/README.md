# @luma/connector-jtl

JTL cloud and on-premise protocol clients and response schemas.

Credentials and transport are supplied explicitly. The caller must approve an on-premise destination before creating a client. Installation permissions and credential storage belong to connections; normalization belongs to `@luma/app-jtl`. Exports point to compiled `dist` output.

## Public entry points

- `@luma/connector-jtl`
- `@luma/connector-jtl/schemas`
